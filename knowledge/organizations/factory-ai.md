Factory builds agent-native software-development tooling, sold as Droids that automate coding, testing and deployment. It enters this corpus with Signals, a system that turns the agent's own interactions into daily changes to the agent's codebase ([a coding agent rewrites its own codebase every day](/developments/2026-01-27-factory-ai-updates-itself-daily.md)), one of the first vendor-shipped instances of the [recursive self-improvement](/themes/recursive-self-improvement.md) loop.
